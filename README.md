## ✅ 구매할 타이밍? 딱지금!

## 📌 프로젝트 소개
매일 변동되는 상품 가격과 예측하기 어려운 특가 타이밍으로 구매를 망설이신 적이 있으신가요?

**딱지금**은 관심 있는 상품의 가격을 지속적으로 추적하고,  
최저가에 도달하거나 사용자가 설정한 목표 가격 이하로 내려갈 경우 알림을 제공하여  
가장 적절한 구매 시점을 놓치지 않도록 돕는 가격 추적 서비스입니다.

## 📃 기능 요약
🔔 **알림**
> 관심 상품이 최저가에 도달하거나 사용자가 설정한 목표 가격 이하로 내려가면 FCM 푸시 알림을 전송합니다.<br/>
> 알림을 클릭하면 앱으로 진입하며, 버튼을 통해 해당 상품의 실제 구매 페이지로 즉시 이동할 수 있습니다.

📋 **상품 리스트 관리**
> 등록한 상품을 리스트 형태로 한눈에 확인할 수 있습니다.<br/>
> 상품 삭제, 검색 등 빠른 관리가 가능하도록 구성되어 있습니다.

📈 **가격 변동 그래프**
> 최근 2주간의 가격 변동 내역을 그래프로 시각화하여 제공합니다.<br/>
> 가격 흐름을 직관적으로 파악하고 구매 타이밍 판단에 도움을 줍니다.

⚡ **간편한 상품 등록**
> 외부 쇼핑몰에서 공유하기를 통해 앱으로 바로 진입하여 상품을 간편하게 등록할 수 있습니다.<br/>
> 또한 클립보드에 복사된 URL을 자동 감지하여 빠른 상품 등록을 지원합니다.
